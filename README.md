# Data Analytics Portfolio

A collection of data analytics and business intelligence projects focused on extracting insights from real-world datasets, building practical reporting tools, and supporting data-driven decision making.

## Projects

| Project | Description | Tools & Frameworks |
|---------|-------------|--------------------|
| **[DoorDash Delivery Efficiency Analysis](https://github.com/yashvardhanraii/doordash-delivery-analysis)** | Analysis of historical DoorDash delivery data in Brisbane to identify efficient regions, peak delivery hours, and operational patterns | Python · Pandas · Plotly · QDAVI |
| **[Personal Finance Spending Dashboard](https://github.com/yashvardhanraii/personal-finance-spending-analysis-dashboard)** | End-to-end finance analytics project analysing spending patterns, category distribution, and monthly trends with a dynamic year filter | Excel · MySQL · Power BI |
| **[Job Search Tracker Excel Template](https://github.com/yashvardhanraii/job-search-tracker-excel-template)** | Excel-based job application tracker and dashboard template designed to organise applications, track follow-ups, monitor status, and turn the job search process into a simple reporting system | Microsoft Excel · Excel Tables · Formulas · Pivot Tables · Pivot Charts · Dashboard Design |
| **[Automotive Sales & Service Dashboard](https://github.com/yashvardhanraii/automotive-sales-service-dashboard)** | BI dashboard analysing vehicle sales performance, dealer profitability, product demand, and service issues | IBM Cognos Analytics |
| **[Perth Housing Market Dashboard](https://github.com/yashvardhanraii/perth-housing-market-dashboard)** | Excel dashboard analysing housing prices, land size, and property characteristics across Perth suburbs | Microsoft Excel |
| **[Queensland Green Tourism Fleet Strategy](https://github.com/yashvardhanraii/ev-fleet-strategy-analysis)** | Fleet data analysis evaluating the transition from petrol vehicles to hybrid and electric vehicles | Python · Pandas · Matplotlib · QDAVI · TOWS |
| **[Coffee Sales Market Analysis](https://github.com/yashvardhanraii/coffee-sales-market-analysis)** | Python analysis combining coffee sales data and news trends to explore product demand and market opportunities | Python · Pandas · Plotly · QDAVI |
